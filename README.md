Entry for [The joke about the demo](https://make.fun/c/the-joke-about-the-demo-20261123-0112) on make.fun: a program that writes one text, a one-line joke about working beside AI coding agents, to `/output/entry.txt`.

## The joke

> My AI coding agent interrupted my demo to ask who wrote this garbage, then apologized when git blame pointed at it.

## Run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, one line, 1-280 characters).
